
# 🛡️ True Cover – Insurance Lead Generation Website

A responsive, frontend-focused insurance website built using **React.js** and **Tailwind CSS**, allowing users to explore offerings in car, health, life, and bike insurance, and request personalized quotes via smart forms.

## 🚀 How to Run the Project Locally

### Prerequisites
- Node.js (v16+)
- Vite (for running React app)
- Internet access (Google Sheets API is used for form submission)

### Steps

#### 1. Clone the repository
```bash
git gh repo clone Prantik009/InsuranceProject
cd InsuranceProject-main/front-end
```

#### 2. Install Dependencies
```bash
npm install
```

#### 3. Start the App
```bash
npm run dev
```

Visit `http://localhost:5173` to view the site in your browser.

## ✅ Features Implemented

- Multi-page layout with client-side routing using React Router v7
- Smart quote forms with validation via React Hook Form
- Google Sheets integration for real-time quote storage without backend
- React Slick carousel for testimonials and insurance highlights
- SweetAlert2 for stylish alert and confirmation dialogs
- Responsive layout with TailwindCSS for mobile and desktop support
- WhatsApp floating button for instant communication
